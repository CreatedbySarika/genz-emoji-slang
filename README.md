# Gen Z Emoji to Slang Converter 😎➡️💬 #

A simple Python application that translates emojis into their Gen Z slang meanings. This project demonstrates the use of Python dictionaries, functions, user input handling, and basic text processing.

## Features ##

1.Convert emojis into Gen Z slang descriptions\
2.Uses a dictionary for fast emoji lookup\
3.Supports multiple emoji mappings\
4.Beginner-friendly Python project\
5.Easily expandable with new emojis and meanings
